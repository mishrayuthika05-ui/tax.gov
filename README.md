# Tax. gov

A modern web application built with Next.js, TypeScript and Tailwind CSS, deployed on Firebase App Hosting.

## Tech Stack

- Next.js (TypeScript)
- Tailwind CSS
- shadcn/ui
- Firebase App Hosting

## Getting Started

1. Clone the repository

```bash
git clone <your-repository-url>
cd <project-folder>
```

2. Install dependencies

```bash
npm install
```

3. Run the development server

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
